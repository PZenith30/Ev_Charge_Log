# KiloEV

เว็ปแอปสำหรับบันทึกและวิเคราะห์การชาร์จรถยนต์ไฟฟ้า — Next.js 15 + React 19 ไม่มี dependency อื่น

## ความสามารถ

- **สองภาษา** ไทย (ค่าเริ่มต้น) และอังกฤษ สลับได้จากเมนูโปรไฟล์หรือหน้าบัญชี · เก็บแยกในแต่ละเครื่อง

- **Quick Add** บันทึกด่วนจากปุ่มบนแถบบน (จอใหญ่) หรือปุ่มลอยมุมขวาล่าง (มือถือ)
- **บันทึกการชาร์จแบบเต็ม** วันที่ เวลา AC/DC เลขไมล์ SOC พลังงาน ราคา ค่าบริการ รูปแนบ
- **คำนวณอัตโนมัติ** ระยะทาง · SOC ที่เพิ่ม · ค่าใช้จ่ายรวม · km/kWh · km/100kWh · kWh/100km · บาท/km · ยอดสะสม
- **แดชบอร์ด** สถิติรวม 8 ตัว และกราฟ 5 ชุด (พลังงานต่อครั้ง, ค่าใช้จ่ายต่อครั้ง, เทียบ AC/DC, รายเดือน, แนวโน้ม Efficiency)
- **ประวัติการชาร์จ** ค้นหา กรองตามวันที่ ประเภท ช่วงค่าใช้จ่าย เรียงลำดับ แก้ไข และส่งออก CSV
- **ต้นทุนรถ** ค่าไฟ บำรุงรักษา ประกันภัย ภาษี และอื่นๆ พร้อมกราฟสัดส่วนและรายเดือน
- **แจ้งเตือน** บำรุงรักษา ต่อประกัน ต่อภาษี และเตือนเมื่อค่าใช้จ่ายเฉลี่ยต่อเดือนเกินงบ
- **รายงาน** สรุปรายเดือน/รายปี พิมพ์เป็น PDF ได้ และส่งออก CSV
- **รถหลายคัน** เลือกยี่ห้อ/รุ่นจาก dropdown พร้อมเติมความจุแบตและระยะทางให้อัตโนมัติ
- **Dark / Light** และรองรับทั้งมือถือและคอมพิวเตอร์

## ตั้งค่า Supabase (ทำครั้งเดียว)

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com)
2. **SQL Editor → New query** วางไฟล์ [supabase/schema.sql](supabase/schema.sql) ทั้งไฟล์แล้วกด Run
   สร้างตาราง, Row Level Security, บัคเก็ตรูป และ trigger ให้ครบ (รันซ้ำได้ ไม่พัง)
3. **Project Settings → Data API** คัดลอก Project URL และ anon public key
4. คัดลอก `.env.local.example` เป็น `.env.local` แล้วใส่ค่าจริง
5. **Authentication → URL Configuration** ตั้ง Site URL เป็น URL ของเว็ปจริง
   เพื่อให้ลิงก์ยืนยันอีเมลและลิงก์ตั้งรหัสใหม่เด้งกลับมาถูกที่

> **เคยรัน schema.sql ไปแล้วก่อนหน้านี้?**
> รัน [supabase/migration-004-discount.sql](supabase/migration-004-discount.sql) เพิ่ม
> เพื่อให้ช่อง **ส่วนลด** ในหน้าบันทึกการชาร์จใช้งานได้ (รันซ้ำได้ ไม่พัง)
> ถ้ายังไม่รัน การบันทึกจะขึ้นข้อความบอกว่าคอลัมน์ไหนหาย

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 แล้วกด **สมัครสมาชิก** ด้วยอีเมลของคุณ

ถ้าอยากดูหน้าตาแดชบอร์ดทันที ไปที่ **บัญชี & รถของฉัน → ใส่ข้อมูลตัวอย่าง**

## Deploy บน Vercel

push ขึ้น GitHub แล้ว import project ใน Vercel — ตรวจเจอ Next.js เอง
ต้องใส่ environment variable สองตัวนี้ที่ **Project Settings → Environment Variables**

```
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
```

ถ้าไม่ใส่ เว็ปจะขึ้นหน้าบอกวิธีตั้งค่าแทนที่จะพังเงียบๆ

## สถานีชาร์จ (ไม่บังคับ)

หน้า **สถานีชาร์จ** ดึงข้อมูลจาก [Open Charge Map](https://openchargemap.org) ต้องมีคีย์ฟรี

```
OPENCHARGEMAP_API_KEY
```

สมัครที่ [openchargemap.org/site/develop/api](https://openchargemap.org/site/develop/api)
ตัวแปรนี้ **ไม่มี** `NEXT_PUBLIC_` นำหน้า เพราะถูกเรียกผ่าน Route Handler ฝั่ง server
คีย์จึงไม่หลุดไปกับโค้ดหน้าเว็ป และไม่ต้องเจอปัญหา CORS

ถ้าไม่ใส่ หน้าอื่นยังใช้ได้ปกติ หน้าสถานีชาร์จจะขึ้นข้อความบอกว่ายังไม่ได้ตั้งค่า
ข้อมูลใช้สัญญาอนุญาต CC BY-SA จึงมีเครดิตแสดงในหน้าเว็ป

หน้านี้ขอตำแหน่งจริงตั้งแต่เปิดหน้า ถ้าไม่อนุญาตก็ยังเลือกเมืองหรือ **พิมพ์ค้นหาสถานที่** ได้
การค้นหาสถานที่ใช้ [Nominatim](https://nominatim.openstreetmap.org) ของ OpenStreetMap
ผ่าน `/api/geocode` ซึ่งฟรีและไม่ต้องใช้คีย์ จึงไม่มีตัวแปรที่ต้องตั้งเพิ่ม

## ผู้ช่วย AI (ไม่บังคับ)

ปุ่มแชทมุมขวาล่างเป็นผู้ช่วยที่รู้จักทั้งวิธีใช้เว็ปและข้อมูลการชาร์จของคุณ ขับด้วย Gemini

```
GEMINI_API_KEY
GEMINI_MODEL      # ไม่ต้องใส่ ระบบเลือกรุ่นที่บัญชีคุณใช้ได้เอง
```

ขอคีย์ฟรีที่ [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
ตัวแปรทั้งคู่ **ไม่มี** `NEXT_PUBLIC_` นำหน้า เพราะเรียกผ่าน Route Handler ฝั่ง server

**เรื่องความเป็นส่วนตัว** — เมื่อเปิดใช้ ระบบจะส่งค่าสรุปและการชาร์จล่าสุด 25 รายการ
ไปประมวลผลที่ Google ปิดได้ด้วยสวิตช์ **"ส่งข้อมูลการชาร์จของฉันให้ AI"** ที่ท้ายแผงแชท
(ปิดแล้วยังถามวิธีใช้เว็ปได้ แต่ถามตัวเลขของตัวเองไม่ได้)
ข้อมูลที่ส่งไม่มีทะเบียนรถ อีเมล หรือรูปแนบ

## ติดตั้งเป็นแอป (PWA)

เปิดเว็ปแล้วจะมีแถบชวนติดตั้งขึ้นมาเอง หรือติดตั้งเองก็ได้

- **Android / Chrome / Edge** — เมนู ⋮ → ติดตั้งแอป
- **iOS / Safari** — ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- **Windows / macOS** — ไอคอนติดตั้งบนแถบที่อยู่ของเบราว์เซอร์

ติดตั้งแล้วเปิดแบบเต็มจอไม่มีแถบเบราว์เซอร์ มีทางลัดไปหน้าบันทึก ประวัติ และสถานีชาร์จ
และเมื่อ deploy เวอร์ชันใหม่ แอปจะขึ้นแถบ "มีเวอร์ชันใหม่" ให้กดโหลด

**ออฟไลน์ทำอะไรได้บ้าง** — เปิดแอปได้และเห็นหน้าจอ แต่**ดูข้อมูลไม่ได้**
เพราะข้อมูลอยู่บน Supabase ซึ่งต้องต่อเน็ต ถ้าเน็ตหลุดจะขึ้นหน้าแจ้งเตือนแทนที่จะพัง

## การเก็บข้อมูล

| ข้อมูล | ที่เก็บ |
| --- | --- |
| รถ ประวัติชาร์จ ต้นทุน การเตือน การตั้งค่า | ตาราง Postgres บน Supabase |
| รูปแนบ (สลิป / สกรีนช็อต) | Supabase Storage บัคเก็ต `charge-images` (private) |
| ธีม และสถานะ "ดูรถทุกคัน" | `localStorage` (ค่าประจำเครื่อง) |

ทุกตารางเปิด **Row Level Security** ผูกกับ `auth.uid()` ผู้ใช้เห็นและแก้ได้เฉพาะข้อมูลของตัวเอง
anon key เปิดเผยได้โดยไม่มีปัญหา เพราะความปลอดภัยอยู่ที่ RLS ไม่ใช่ที่การซ่อน key

รูปแนบเป็นบัคเก็ตส่วนตัว เข้าถึงผ่าน signed URL อายุ 1 ชั่วโมง
path เป็น `<user_id>/<uuid>.jpg` และ policy ตรวจโฟลเดอร์แรกเทียบกับผู้ใช้ที่ล็อกอิน

## ย้ายข้อมูลจากรุ่นเดิม

ถ้าเคยใช้รุ่นที่เก็บข้อมูลในเบราว์เซอร์ พอล็อกอินครั้งแรกจะเห็นการ์ดในหน้า **บัญชี**
ให้กดย้ายข้อมูลขึ้น Supabase — ระบบอัปโหลดรูปจาก IndexedDB ให้ด้วย แล้วลบของเดิมในเครื่องทิ้ง

## ข้อจำกัด

- แจ้งเตือนเป็นแบบ in-app (เห็นตอนเปิดเว็ป) ไม่ใช่ push notification
- ไฟล์ส่งออก JSON ไม่รวมรูปแนบ เพราะรูปอยู่ใน Supabase Storage
- ยังไม่มี realtime sync ระหว่างแท็บ/เครื่อง (ต้องรีเฟรชเพื่อเห็นการแก้จากเครื่องอื่น)

```
doc/plan.txt          แผนงานและบันทึกการตัดสินใจ
```
