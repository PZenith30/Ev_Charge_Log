# Feature
สามารถใช้ในมือถือและคอมพิวเตอร์ได้
มี Quick Add
หน้าบันทึกการชาร์จ
- มีข้อมูลพื้นฐาน วันที่ เวลาที่ใช้ในการชาร์จ AC/DC
- ข้อมูลรถ เลขไมล์ก่อนชาร์จ เลขไมล์หลังชาร์จ ระยะทางที่วิ่งได้ SOCก่อนชาร์จ SOCหลังชาร์จ
- ข้อมูลพลังงาน จำนวนพลังงานที่ชาร์จ (kWh) ราคา/kWh ค่าบริการเพิ่มเติม ค่าใช้จ่ายรวมต่อครั้ง
- อัตราสิ้นเปลืองเฉลี่ยที่อ่านจากหน้าปัดรถ
- แนบรูปภาพได้ เช่น สลิปธนาคาร ภาพแคปหน้าจอจากแอพชาร์จรถ
ระบบคำนวณอัตโนมัติ
- คำนวณระยะทางที่วิ่งได้จากเลขไมล์ก่อนชาร์จและเลขไมล์หลังชาร์จ
- คำนวณ SOC ก่อนชาร์จและหลังชาร์จ
- คำนวณค่าใช้จ่ายรวมต่อครั้งจากจำนวนพลังงานที่ชาร์จและราคา/kWh
- คำนวณ Efficiency จากระยะทางที่วิ่งได้และจำนวนพลังงานที่ชาร์จ(แสดง2 หน่วย km/kWh และ km/100kWh)
- คำนวณค่าใช้จ่ายสะสม
- คำนวณ บาท/km

# Tech Stack ที่ใช้จริง
- Next.js 15 (App Router) + React 19
- JavaScript ล้วน (.jsx) ไม่ใช้ TypeScript — ลดโอกาสที่ type error จะทำให้ build บน Vercel พัง
- ไม่มี dependency นอกเหนือจาก next / react / react-dom
- CSS เขียนเองใน app/globals.css ด้วย CSS variables (ไม่ใช้ Tailwind หรือ UI library)
- กราฟทุกตัวเป็น SVG ที่เขียนเอง ไม่มี chart library
- ทุกหน้าเป็น Client Component เพราะข้อมูลอยู่ในเบราว์เซอร์ทั้งหมด

# การเก็บข้อมูล (ไม่มี backend / ไม่มีฐานข้อมูล)
- localStorage คีย์ `evlog.v1` — รถ ประวัติการชาร์จ ต้นทุน การเตือน และการตั้งค่า
- IndexedDB ชื่อ `evlog-images` — รูปแนบ (สลิป / สกรีนช็อต) เพราะเกินโควตา ~5MB ของ localStorage
- รูปถูกย่อเหลือด้านยาวสุด 1600px และบีบเป็น JPEG คุณภาพ 0.82 ก่อนเก็บ
- รูปที่ไม่มีรายการไหนอ้างถึงจะถูกลบอัตโนมัติตอนเปิดแอป (garbage collect)
- ข้อมูลอยู่เฉพาะเบราว์เซอร์เครื่องที่ใช้ — เปิดเครื่องอื่นจะไม่เห็นข้อมูล
  ทางแก้: ปุ่มสำรอง/กู้คืนเป็นไฟล์ JSON ในหน้าบัญชี (เลือกได้ว่าจะรวมรูปหรือไม่)

# ข้อจำกัดที่ต้องรู้
- Login Admin/Admin ตรวจสอบฝั่งเบราว์เซอร์เท่านั้น เป็นการล็อกหน้าจอ ไม่ใช่การป้องกันข้อมูลจริง
  ถ้าต้องการความปลอดภัยจริงต้องเพิ่ม backend + ฐานข้อมูล (เช่น Vercel Postgres + NextAuth)
- ระบบแจ้งเตือนเป็นแบบ in-app (เห็นตอนเปิดเว็ป) ไม่ใช่ push notification เพราะไม่มี server
- ข้อมูลไม่ sync ข้ามเครื่อง

# การตัดสินใจที่ตกลงกับผู้ใช้
- เก็บข้อมูลแบบ localStorage + IndexedDB
- กราฟเขียนเป็น SVG เอง ไม่พึ่ง CDN / library
- ลิสต์ยี่ห้อ-รุ่นรถ EV ฝังในตัวแอป (lib/data.js) พร้อมความจุแบตและระยะทางของแต่ละรุ่น
  เลือก "อื่นๆ" เพื่อพิมพ์ยี่ห้อ/รุ่นเองได้
- รายงาน: สรุปรายเดือน/รายปีในเว็ป + ปุ่มพิมพ์เป็น PDF + ส่งออก CSV

# ส่วนที่ทำเพิ่มจากที่ระบุใน plan เดิม
- แสดง kWh/100km เพิ่มจาก km/kWh และ km/100kWh (เป็นหน่วยมาตรฐานที่ใช้เทียบกันทั่วไป)
- เลขไมล์ก่อนชาร์จเติมให้อัตโนมัติจากเลขไมล์หลังชาร์จของครั้งก่อนหน้า (ของรถคันเดียวกัน)
- ค่าใช้จ่ายรวมคำนวณให้อัตโนมัติ แต่แก้ทับได้ถ้ายอดจริงไม่ตรง
- ราคา/kWh เริ่มต้นแยก AC และ DC ตั้งค่าได้ในหน้าบัญชี
- สลับดูข้อมูลรายคัน หรือ "รถทุกคัน" ได้จาก dropdown แถบบน
- ปุ่ม "ใส่ข้อมูลตัวอย่าง" สำหรับดูหน้าตาแดชบอร์ด/รายงานได้ทันที
- ส่งออก CSV มี BOM นำหน้า เพื่อให้ Excel อ่านภาษาไทยไม่เพี้ยน

# วิธีรัน
  npm install
  npm run dev          เปิด http://localhost:3000
  npm run build        ตรวจว่า build ผ่านก่อน deploy

# วิธี Deploy บน Vercel
- push ขึ้น GitHub แล้ว Import Project ใน Vercel — ตรวจเจอ Next.js เองไม่ต้องตั้งค่าอะไร
- หรือใช้ `npx vercel` จากโฟลเดอร์นี้
- ไม่ต้องตั้ง environment variable ใดๆ เพราะไม่มี backend

# สิ่งที่ยังไม่ได้ทำ / ต่อยอดได้
- ยังไม่มี backend จึงยังไม่มี sync ข้ามเครื่อง และไม่มี login จริง
- ยังไม่มี push notification (ต้องมี server + service worker)
- ยังไม่ได้ทำ PWA ให้ติดตั้งลงหน้าจอมือถือ
- ยังไม่มีการนำเข้าข้อมูลจาก CSV (มีแต่ส่งออก)
